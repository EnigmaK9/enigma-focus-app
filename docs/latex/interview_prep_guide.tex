\section{Project Overview \& Executive Summary}
\textbf{Enigma Focus} is a production-grade, privacy-first, zero-friction Android application engineered in modern Kotlin and Jetpack Compose. Its mission is to eliminate compulsive digital distraction and enforce mindful barriers through hardware-level GPU controls and accessibility-level system interception.

\begin{tcolorbox}[colback=codeBg,colframe=accentGreen,title=\textbf{Core Engineering Value Proposition}]
Unlike conventional timer apps that rely on easily bypassed foreground overlays, Enigma Focus combines:
\begin{itemize}[noitemsep]
    \item \textbf{Instant System-Level Interception}: Real-time detection via \texttt{AccessibilityService} and 300ms watchdog loop ($<20$ms response).
    \item \textbf{Hardware GPU Monochrome}: Direct Daltonizer display compositor control (\texttt{WRITE\_SECURE\_SETTINGS}).
    \item \textbf{Aggressive Bedtime Lockout}: Instant screen-on locking during sleep hours with strict 60s emergency cap.
    \item \textbf{Unix Philosophy Architecture}: Decoupled headless engines, JSON Lines logging, and full CLI IPC via Broadcast Intents.
\end{itemize}
\end{tcolorbox}

\section{Key Technical Deep Dives (Interview Talking Points)}

\subsection{1. Zero-Friction App Interception: Accessibility vs UsageStats}
\begin{itemize}
    \item \textbf{Why Accessibility Service?} Android's \texttt{UsageStatsManager} suffers from 1--5 second polling latency and cannot block apps proactively. \texttt{FocusAccessibilityService} receives \texttt{TYPE\_WINDOW\_STATE\_CHANGED} and \texttt{TYPE\_WINDOWS\_CHANGED} within $<20$ milliseconds.
    \item \textbf{Optimized Accessibility Overlay}: Uses \texttt{TYPE\_ACCESSIBILITY\_OVERLAY} with \texttt{FLAG\_NOT\_TOUCH\_MODAL} and \texttt{FLAG\_LAYOUT\_IN\_SCREEN}, attached directly through the system \texttt{WindowManager} hosting an isolated ComposeView tree.
    \item \textbf{Keyguard Coexistence}: Evaluates \texttt{KeyguardManager.isKeyguardLocked}. It waits for \texttt{ACTION\_USER\_PRESENT} before presenting the sleep nudge, preventing conflicts with the system lockscreen PIN/fingerprint pad.
\end{itemize}

\subsection{2. GPU Daltonizer Engine (Hardware Monochrome Mode)}
\begin{lstlisting}[language=Kotlin]
Settings.Secure.putInt(contentResolver, "accessibility_display_daltonizer_enabled", 1)
Settings.Secure.putInt(contentResolver, "accessibility_display_daltonizer", 0) // 0 = Monochrome
\end{lstlisting}
\begin{itemize}
    \item Rather than rendering an expensive full-screen grayscale tint shader (which degrades battery and CPU), Enigma Focus instructs the SurfaceFlinger display compositor to run monochrome on hardware GPU pipelines.
    \item Requires \texttt{android.permission.WRITE\_SECURE\_SETTINGS}, grantable via ADB or Shizuku without requiring root.
\end{itemize}

\subsection{3. Aggressive Bedtime Lockout (Anti-Relapse Watchdog)}
\begin{itemize}
    \item Monitors the overnight interval (\texttt{22:30 -- 06:30}).
    \item Enforces a mandatory 10-second mindful breathing challenge (*Inhale, Hold, Exhale*) before enabling the emergency pause.
    \item Limits emergency access to \textbf{strictly 60 seconds}. When the timer expires, the background 300ms watchdog immediately re-triggers the blocking overlay and sends the user Home.
    \item \textbf{Snooze Invalidation}: Registering a \texttt{BroadcastReceiver} for \texttt{ACTION\_SCREEN\_OFF} ensures that putting the phone down immediately cancels any active 1-minute grace period.
\end{itemize}

\subsection{4. Unix Philosophy in Mobile Systems}
\begin{itemize}
    \item \textbf{Declarative Configuration}: Supports full config export/import in human-readable JSON (\texttt{enigma\_config.json}) with hot live-reload.
    \item \textbf{Composability \& CLI}: Exposes 14 Broadcast Intents enabling control via terminal or Tasker:
    \begin{lstlisting}[language=bash]
adb shell am broadcast -a com.example.enigmafocus.action.START_SESSION --ei duration_minutes 25
adb shell am broadcast -a com.example.enigmafocus.action.GET_STATUS
    \end{lstlisting}
    \item \textbf{Silent Telemetry in JSON Lines}: All events logged to \texttt{focus\_events.jsonl} locally (zero cloud, 100\% private) with automatic rotation at 5,000 lines.
\end{itemize}

\section{Likely Technical Interview Questions \& Model Answers}

\subsubsection*{Q1: How do you prevent memory leaks when injecting ComposeViews into an AccessibilityService?}
\textbf{Model Answer:} ``In an AccessibilityService, there is no standard Activity lifecycle. To safely render Jetpack Compose in a \texttt{WindowManager} overlay, I implemented a custom \texttt{OverlayLifecycleOwner} implementing both \texttt{LifecycleOwner} and \texttt{SavedStateRegistryOwner}. When the overlay is dismissed, we explicitly dispatch \texttt{ON\_PAUSE}, \texttt{ON\_STOP}, \texttt{ON\_DESTROY} and invoke \texttt{windowManager.removeView(composeView)}, preventing orphaned view trees and coroutine scope leaks.''

\subsubsection*{Q2: How do you handle battery optimization and aggressive OEM killers (e.g., Xiaomi MIUI/HyperOS)?}
\textbf{Model Answer:} ``We utilize a dual-layer survival architecture:
1. An official \texttt{AccessibilityService}, which is granted high-priority lifecycle protection by Android's accessibility framework.
2. A persistent \texttt{ForegroundService} with \texttt{FOREGROUND\_SERVICE\_TYPE\_SPECIAL\_USE} and ongoing notification during active timer sessions.
3. \texttt{BootReceiver} listening to \texttt{ACTION\_BOOT\_COMPLETED} and \texttt{MY\_PACKAGE\_REPLACED} to restore scheduled interval listeners immediately upon boot.''

\subsubsection*{Q3: How did you test concurrency and overnight interval calculations?}
\textbf{Model Answer:} ``I wrote a comprehensive test suite in JUnit 4 using multi-threaded pools (\texttt{Executors.newFixedThreadPool(16)}) simulating 1,000 concurrent access requests across day boundaries, leap hours, and daylight savings transitions. For overnight intervals (e.g., 22:30 to 06:30), the algorithm evaluates cross-midnight minutes math ($start > end$) and maps Saturday--Sunday rollover with 100\% test coverage.''
